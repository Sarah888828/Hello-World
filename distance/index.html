목적지는 목록에서 선택하거나, Kakao 지도에 연결한 뒤 지도 클릭으로 두 번째 점을 지정할 수 있습니다.

검색어로 지도 앱을 열어 주소를 확인하세요. 검색만으로 거리 좌표가 자동 입력되지는 않습니다.

네이버에서 출발지 검색 ↗ 카카오에서 출발지 검색 ↗
내 위치에서 직선거리 -- km 위치 권한을 허용하면 측정할 수 있어요.
Google 지도 길찾기 ↗ 네이버 지도에서 실제 길찾기 ↗ 카카오맵 검색 ↗

ⓘ 위치 권한은 거리 계산에만 사용하며 서버에 전송하거나 저장하지 않습니다.

직선거리는 확인된 주소 대표 좌표를 사용한 근사값이며 실제 도로 이동 거리·소요시간이 아닙니다. 도로 경로는 선택한 주차장 이름과 주소를 지도 앱에 전달해 확인합니다. 현재 위치는 버튼을 눌렀을 때 브라우저에서만 읽으며 이 사이트 서버에 저장하지 않습니다. 위치 측정은 HTTPS에서 지원됩니다.

지도 연결 설정: 실제 Kakao 지도를 표시하려면 Kakao Developers에서 JavaScript 키를 발급하고 배포 도메인을 허용 목록에 등록한 뒤, 이 페이지의 data-kakao-javascript-key 설정값에 키를 넣어야 합니다. 현재 키가 없어 지도 대신 설정 안내가 표시됩니다. 실제 키를 GitHub에 커밋하지 마세요.
