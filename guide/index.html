QUICK FAQ

자주 묻는 질문

페이지에 보이는 주차면 수가 현재 빈자리 수인가요?

아니요. 표시된 값은 공식 현황의 총 주차면 수입니다. 실시간 빈자리 수나 만차 여부는 연동되어 있지 않으니 현장 또는 공식 안내를 확인해 주세요.

거리측정 결과가 실제 도로 거리인가요?

아니요. 좌표가 등록된 불당 제1주차장에 한해 현재 위치와 주소 대표점 사이 근사 직선거리를 계산합니다. 실제 도로 경로와 시간은 지도 앱 길찾기를 이용하세요.

주차장 정보가 잘못되었으면 어떻게 제보하나요?

문의 게시판에서 “정보 정정/제보” 유형을 선택하고 주차장명과 확인한 내용을 적어 주세요. 제보는 즉시 사이트에 반영되지 않으며 공식 출처 확인 후 반영해야 합니다.

즐겨찾기는 계정에 저장되나요?

아니요. 즐겨찾기는 현재 브라우저의 로컬 저장공간에만 저장됩니다. 다른 기기나 브라우저와 동기화되지 않습니다.

거리측정 화면에서 Kakao 지도가 안 보이는 이유는 무엇인가요?

Kakao Developers JavaScript 키와 허용 도메인을 설정해야 합니다. 키가 설정되기 전에는 페이지가 설정 안내 상태로 표시됩니다. 키 등록 후에는 지도에서 두 점 사이 직선거리를 잴 수 있으며, 실제 도로 경로가 아닙니다.
